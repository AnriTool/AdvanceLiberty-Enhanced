# Экспериментальное прицеливание мышью

Включение: **Esc → On-foot bindings → Mouse aim (exp.) → On**.
Затем Esc → **Save and return**. По умолчанию режим выключен.

В Enhanced пешком персонаж поворачивается к курсору; J и ЛКМ стреляют
в направлении взгляда. WASD/стрелки двигают по прежним экранным осям,
независимо от взгляда. Все переназначения действуют как раньше.
Sprint по-прежнему блокирует Fire, Jump сохраняет своё действие.
При курсоре непосредственно у ног сохраняется последний угол.

Режим действует только в пешем Enhanced-управлении. Classic, транспорт,
пауза/меню настроек и потеря фокуса отключают подмену. Выход мыши из окна
или игровой области с чёрными полосами также её отключает. Активные кнопки
геймпада используют исходную раскладку без мышиного прицела.

Конфиг: `MouseAim = true` перед `[GBA]` в controls.cfg. Отсутствующее поле
означает false; F5 перечитывает значение. Discard and return отменяет
изменения, Save and return сохраняет. F8 → Classic отключает режим, не
стирая сохранённую настройку.

## Реализация

mouse_aim.rs избирательно подменяет пять нативных чтений угла USA ROM,
найденных в [исследовании](MOUSE_AIM_RESEARCH.md). Проверяются инструкция
ROM, адрес физики, указатель текущего игрока и его тип. Подмена применяется
к анимации, размещению частей и инициализации выстрела; физические чтения,
рассчитывающие движение WASD, получают исходный угол. ROM, DLL и сам угол
в гостевой памяти не переписываются. Перехват RtApi действует и при внутренних
выходах AOT через общий активный API. В interpreter-режиме функция недоступна.

Desktop преобразует мышь через SDL_RenderWindowToLogical, учитывая размер
окна, letterboxing и HiDPI. Для Enhanced сохраняется проекция корня игрока
из реально показанной интерполированной сцены, её масштаб и мировая позиция.
Обратная проекция курсора задаёт мировую цель; направление вычисляется
от актуальной физической позиции игрока. Это учитывает существующую задержку
представления камеры в 6 кадров. HUD не участвует в преобразовании.
Оригинальный вывод использует свои размеры и проекцию без широкого сдвига.

Object projection дополнен только метаданными корня для прицела. Растеризация,
материалы, HUD и параметры камеры сохраняют прежние алгоритмы. Wide остаётся
854×480 со сдвигом центральной области на 67 пикселей.

## Запись и повтор

При первом активном прицеливании Session создаёт рядом с input.gba-input
файл `aim.gba-aim`. В нём записаны изменения эффективного угла по кадрам:

```text
gba-aim v1
0 none
730 128
1050 768
1600 none
```

Углы 0..1023 соответствуют полному обороту: 0 — вверх, 256 — вправо,
512 — вниз, 768 — влево. `none` возвращает исходное поведение. До первого
включения файла нет. Обычные старые записи продолжают работать без него.

Runtime автоматически читает aim.gba-aim рядом с входным input.gba-input;
поэтому replay.ps1 поддерживает такие записи без новых обязательных параметров.
Для отдельных опытов есть `--aim-input FILE.gba-aim`. Неправильный заголовок,
угол, порядок кадров или отсутствие начальной строки кадра 0 отклоняются.
Сам поток не включает пользовательскую настройку и не меняет controls.cfg.

## Проверка 24 октября 2026

Артефакты: `artifacts/aim-20261024/`.

- 113 runtime-тестов и тест AOT; отдельно три SDL-проверки. Новый SDL-тест
  проверяет включение/отмену/сохранение/перезапуск, последнюю строку меню,
  размеры 240/720/854, преобразование курсора, мёртвую зону, Classic и фокус.
- Полный повтор последней исходной сессии: 4291 видео-/аудиохеш совпал,
  Enhanced 16:9 принял 780 сцен, rejected=0, material_clamps=0. Осталось
  исходных 11678 интерпретированных инструкций. Все 3404 хеша показанных
  Enhanced-кадров также совпали со сборкой до реализации прицела.
- Фиксированный угол 256: все 1500 видео-/аудиохешей совпали с прежним
  исследовательским прототипом; запись нового потока и повтор совпали.
  Тем самым сохранён ранее подтверждённый маршрут с независимым WASD.
- Маршрут 4291 кадр с переключением между 0, 128, 256, 512, 640, 768,
  900, 1023 и отключением прицела: запись и повтор совпали по всем хешам.
  Enhanced принял 846 сцен, rejected=0, material_clamps=0. Интерпретаций —
  18385; новый маршрут не заявляется полностью покрытым AOT.
- Изображения подтверждают поворот тела и стрельбу по диагонали. Проверки
  проекции отдельно охватывают историческое положение, zoom и широкий сдвиг.
  Сохранение и пользовательские конфиги в опытах не использовались для записи.

Ограничения: это первая экспериментальная версия, проверенная на локальной
записи с пешим стрелковым оружием. Полного прогона всех оружий, рукопашного
боя, автозахвата цели, миссионных кат-сцен и всех переходов ещё нет.
Визуальный отклик сохраняет существующую задержку камеры и частоту оригинальных
анимаций. Для возврата выключите Mouse aim (exp.) и сохраните настройку.
