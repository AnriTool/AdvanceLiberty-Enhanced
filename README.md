# GTA Advance для ПК

Это рабочий каталог игры. Исходники, локальные зависимости, запуск, нативный
код, ROM и пользовательские данные находятся здесь. Каталог можно переместить
целиком: пути запуска вычисляются относительно скриптов.

## Запуск

Двойной щелчок по **Play.cmd** или из PowerShell:

```powershell
.\play.ps1
```

Запуск работает из любого текущего каталога. Перед запуском выполняется
инкрементальная сборка; `-SkipBuild` использует готовый исполняемый файл.
Новая игра не нужна: существующий прогресс и управление перенесены.

Используется USA ROM из `roms/usa.gba`. Это локальная копия предоставленного
пользователем ROM. Европейская версия пока не поддерживается этим профилем.

| Где | Назначение |
| --- | --- |
| `src/` | Игровой runtime, Enhanced-рендер, камера, ввод, звук и диагностика |
| `tools/aot/` | Статический рекомпилятор и вспомогательные инструменты |
| `vendor/` | Локальные исходники ARM, модели GBA и базового рекомпилятора |
| `native/usa/` | Четыре активные DLL, сгенерированный C и манифест загрузки |
| `native/usa/coverage/` | Накопленные входные данные для пересборки DLL |
| `roms/` | Локальные ROM пользователя |
| `data/saves/usa.sav` | Текущее игровое сохранение; `.bak` — резервное |
| `data/config/controls.cfg` | Привязки клавиатуры и мыши, режим управления |
| `data/config/enhanced.cfg` | Сохранённые параметры Enhanced Options |
| `data/sessions/` | Записи ввода, начальных сохранений, видео/аудиохешей и откатов |
| `target/` | Результаты сборки Cargo; игра — `target/release/gta-advance.exe` |
| `artifacts/` | Результаты повторов и проверок, журналы сборки |
| `docs/` | Актуальное устройство проекта и исторические исследования |

## Управление и изображение

Enhanced включён по умолчанию. Меню и неподдержанные сцены используют исходный
вывод. Заголовок показывает FPS, долю нативного исполнения, количество
интерпретированных инструкций и состояние Camera preview.

Управление Enhanced на клавиатуре включено по умолчанию и переключается
автоматически по текущему управляемому объекту игры:

| Действие | Пешком | В автомобиле |
| --- | --- | --- |
| Движение | WASD / стрелки | W/S — газ и тормоз/задний ход, A/D — руль |
| Выстрел / удар | J / левая кнопка мыши | — |
| Бег | Shift | — |
| Прыжок | Space | — |
| Войти / выйти из транспорта | F | F |
| Сменить оружие | Tab | Исходный Select на Tab |
| Ручник | — | Space |
| Сигнал / сирена | — | Shift |
| Специальная миссия | — | Caps Lock |
| Вращение башни | — | Ctrl + A/D |
| Пауза игры | Enter | Enter |

| Клавиша | Общее действие |
| --- | --- |
| F6 | Enhanced / полностью оригинальный рендер |
| F8 | Enhanced / стандартное управление GBA |
| F11 | Полный экран |
| F5 | Перечитать `controls.cfg` |
| Esc | Enhanced Options: настройки и выход из игры |
| P | Пауза исполнения |

**Esc** открывает нативное меню **Enhanced Options** поверх текущей сцены,
в том числе поверх оригинальной паузы. Исполнение игры и звук остановлены,
пока открыто меню. Стрелки выбирают строку, Enter меняет значение или открывает
раздел; также можно нажимать строки мышью. Геймпад: Guide открывает меню,
D-pad / A / B — навигация / выбор / назад.

Доступны режим Enhanced/Classic, три независимых раздела привязок,
рендер Enhanced/Original, текстуры Perspective / Affine (экспериментальная
эстетика PS1) и полный экран. В разделе привязок Enter заменяет все клавиши
выбранного действия, Insert добавляет альтернативу, Delete очищает действие.
После Enter/Insert нажмите нужную клавишу или кнопку мыши. Esc отменяет захват.
Конфликты и зарезервированные кнопки отклоняются без изменения профиля;
Classic не позволяет оставить кнопку GBA без привязки.

В **HUD size** можно уменьшить HUD до 85%, 75%, 65% или 50%:
**All elements** задаёт общий размер, **Radar and markers** — радар вместе с метками,
**Status and weapon** — часы, деньги, здоровье, розыск и значок оружия,
**Messages** — надписи и сообщения фонового UI. Left/Right меняют размер,
**Reset HUD sizes** возвращает 100%. Радар сохраняет левую верхнюю привязку,
показатели — правую верхнюю, сообщения — нижнюю центральную.
Масштабирование работает в Enhanced-виде мира; оригинальный вывод и игровые
меню сохраняют исходный размер. Размеры сохраняются вместе с остальными настройками.

**Save and return** применяет изменения и сохраняет их для следующего запуска.
Esc в подразделе возвращает на главный экран настроек; Esc на главном экране
или **Discard and return** отменяет все несохранённые изменения.
Настройки графики сохраняются в `data/config/enhanced.cfg`, управление — в
`controls.cfg`; перед сохранением создаётся `controls.cfg.options-backup`.
Открытие меню само по себе файлы не изменяет. Удержанные кнопки не передаются
игре после закрытия, пока их не отпустить. Выход через меню запрашивает
подтверждение; несохранённые настройки при выходе отменяются.

Привязки редактируются в `data/config/controls.cfg`: `[GBA]` содержит исходные
десять кнопок, `[OnFoot]` и `[Vehicle]` — отдельные игровые действия.
После ручных изменений нажмите F5. `Mode = Enhanced` или `Mode = Classic` задаёт
режим при следующем запуске; F8 переключает его только до закрытия игры.
Прежняя раскладка сохранена в `data/config/controls-gba-backup.cfg`.
Профили полностью независимы: `[GBA]` применяется только в Classic и меню.
Назначение в нём R на S или Select на Shift не меняет управление Enhanced.
Pause и дополнительные кнопки также можно переназначать внутри профилей.
Удерживаемое действие при смене
контекста не превращается в другое действие без отпускания клавиши;
движение WASD при посадке и выходе продолжается.

Мышь стреляет в текущем направлении персонажа. Геймпад пока сохраняет
исходную раскладку GBA. [Формат настроек и проверки](docs/CONTROLS.md).

Поддерживается SDL GameController. Параметры `-OriginalRenderer` и
`-AffineTextures` выбирают исходный вывод и экспериментальные аффинные
текстуры при запуске, перекрывая сохранённые параметры. `-Rom`, `-SavePath`, `-ControlsPath` задают другие пути.

По умолчанию каждый запуск создаёт новую запись в `data/sessions/`.
Закрывайте игру через **Esc → Quit game → Quit game** или крестик окна для завершённого отчёта; промежуточный аудит
обновляется во время игры. `-NoRecord` отключает запись;
`-SessionDirectory NEW_DIRECTORY` задаёт её каталог.

## Сборка и проверка

Нужны Rust/Cargo, MSVC Build Tools и CMake. SDL собирается автоматически
из зависимости Cargo; отдельная SDL DLL для запуска не нужна.
Первой сборке нужен доступ к зависимостям Cargo или заполненный локальный кэш.

```powershell
.\build.ps1
.\build.ps1 -Tools
.\test.ps1 -Sdl
```

`-Tools` дополнительно собирает рекомпилятор и утилиты дизассемблирования.
`-Offline` у сборки и тестов использует только локальный кэш.
Исходники `vendor/` уже включают нужные изменения, скачивать или патчить
отдельный проект перед сборкой не требуется.
В конфигурации Cargo выбрана последовательная сборка: это устраняет зависание
параллельных процессов MSBuild при сборке SDL в текущем Windows-окружении.

Для повтора завершённой записи с текущими DLL:

```powershell
.\replay.ps1 -Session session-597998b6ac214f5490c03c2d4fe583aa
```

Повтор работает с копией начального сохранения в новом `artifacts/` и
сравнивает все видео- и аудиохеши с записью. По умолчанию требуется ноль
интерпретаций. `-AllowInterpreter` позволяет исследовать ещё не покрытый
маршрут; `-OutputDirectory NEW_DIRECTORY` задаёт каталог результата.

## Нативный код

Порядок и пути библиотек заданы в `native/usa/manifest.json`. Во время игры
код не компилируется. Непокрытые инструкции пока могут учитываемо перейти
в интерпретатор: ноль на проверенных маршрутах не доказывает покрытие всей игры.

Для пересборки DLL нужен **MinGW x64 GCC**, отдельно от MSVC для Rust:

```powershell
.\tools\rebuild-native.ps1 -NativeProfile sessions
```

По умолчанию результат остаётся в новом `artifacts/native-build-.../`.
`-Install` устанавливает успешно собранные DLL и C в `native/usa/`;
`-NativeProfile all` пересобирает все четыре. `-Gcc PATH` задаёт компилятор.
Сначала новые откаты объединяют с соответствующим накопленным CSV в
`native/usa/coverage/`; затем пересобирают профиль и проверяют запись.

ROM, сгенерированные из него C/DLL, сохранения и записи предназначены для
локальной работы. Лицензии исходных зависимостей находятся в `vendor/`.
