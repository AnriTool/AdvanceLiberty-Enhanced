# Плавные автомобили и спрайты из исходных тайлов

## Причина рывков

Для OBJ без доказанного физического корня прежняя защита разрешала
сглаживание только при одинаковом растеризованном bitmap. Поворот OAM
или изменение масштаба камеры меняет такой bitmap даже при неизменном
исходном рисунке автомобиля. Поэтому машина переставала сглаживаться.

В USA ROM найдена проверяемая связь: функция `08016ef0` получает
контроллер автомобиля. Его +48 ссылается на физического родителя, +60 —
на OBJ descriptor; родитель +24 — на позицию, +28 — обратно на контроллер.
Контроллер +52 содержит callback `08016ef1`. Все связи и совпадение позиции
с descriptor проверяются при наблюдении callback. Ни один адрес конкретного
автомобиля не зафиксирован.

При проецировании автомобиля descriptor уже непосредственно читает его
физическую позицию. Для motion anchor используется именно проверенное
проекционное значение: к концу загрузки графики физика может продвинуть
позицию ещё раз. Возраст ссылки и проверки owner/node/generation остаются.
Трансляция теперь сглаживается также при изменении bitmap.

## Поворот

Для проверенных автомобилей с одинаковым исходным изображением и размером
интерполируются короткая дуга угла и масштаб отдельно. Линейная смесь
коэффициентов матрицы сжимала бы автомобиль в середине поворота, поэтому
не используется. Проверяется ортогональная форма матрицы; скачки более
60 градусов и смена исходной картинки не смешиваются. Положение продолжает
сглаживаться независимо от этой проверки вращения. Туловище персонажа
не получает интерполяцию автомобильного вращения.

## Качество спрайтов при отдалении

Прежний Enhanced сначала получал уже уменьшенный/повёрнутый bitmap на сетке
GBA, затем увеличивал его до 720×480. Теперь исходный OBJ рисунок сначала
декодируется из VRAM tiles и palette; координаты обратного affine sampling
считаются для каждого пикселя сетки Enhanced. Дополнительный zoom камеры
учитывается до выборки texel. Это nearest sampling исходного рисунка,
без генерации новых деталей, размытия или изменения игровых размеров.

Размер спрайта по-прежнему меняется вместе с миром при отдалении камеры.
Убрана промежуточная растеризация мирового спрайта на сетке 240×160,
терявшая тонкие детали. Исходная OAM матрица пока имеет точность GBA,
однако между обновлениями автомобилей её угол/масштаб уже сглаживаются.

Для диагностики и сравнения с PPU сохраняется исходный bitmap. HUD
использует прежнюю сетку; F6 Original показывает исходный framebuffer.
Гостевые CPU/IO/OAM/VRAM, ввод, аудио и сохранения не меняются.

## Проверка

`local-output/vehicle-sprites-20261023/verify.py` и `verification.json`:

- поездка a184: 3658 кадров;
- последняя пользовательская запись 2ebc: 9798 кадров;
- бег: 4006 кадров;
- удар битой: 3441 кадр.

Все 20 903 исходных видео- и аудиохеша совпадают с записями.
В двух поездках проверены 18 995 применённых смещений автомобилей;
из них 4830 приходятся на переходы с изменившимся legacy bitmap, которые
раньше прерывали сглаживание. Проверены 3497 промежуточных поворотов:
угол следует короткой дуге, а масштаб не проваливается в середине.
Численные ошибки находятся на уровне округления f64.

На реальных изображениях бега и удара нет внутрипозового скольжения тела.
Исходные привязки и legacy bitmap полностью совпадают с прошлой проверенной
версией. Контактный лист `bat-regression.png` проверен визуально.
Изображение Enhanced намеренно меняется из-за прямого sampling тайлов.

57 обычных тестов проходят, включая сравнение исходной и новой выборки
на целой сетке с PPU для форматов/поворотов/flip/отрицательных координат,
восстановление тонкого texel, полностью потерянного при уменьшении GBA,
проверку физической привязки автомобилей, короткого перехода 175→−175
градусов и отсутствия сжатия при повороте.

В a184 все 710 сцен приняты, отказов нет. В последней записи остаются
103 отказа режима окон `3741`, обработанного прежним fallback Original;
полное покрытие всех графических режимов этой проверкой не заявляется.

`cars-before-after.gif` сравнивает движение в последней записи,
`sprite-detail.png` показывает крупно исходные Enhanced пиксели до/после
без дополнительной фильтрации. Матрицы, фактически применённый zoom и
признаки vehicle/hires добавлены в диагностические sprite CSV.
Release desktop пересобран; дополнительные диагностические файлы при
обычном запуске не записываются.
