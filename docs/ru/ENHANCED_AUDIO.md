# Enhanced Output

[English](../en/ENHANCED_AUDIO.md) | **Русский**

Обычный `Play.bat` включает Enhanced Output по умолчанию.
Для сравнения с прежним аппаратным звуком: `Play.bat -OriginalAudio`.
Явный флаг `Play.bat -EnhancedAudio` также поддерживается.
Это параметр запуска, он пока не записывается в настройки ПК.

Использованы DSP-алгоритмы из JRickey/gba-recomp, базовая ревизия
`de4edf59b872d887046d6a3b005e2df551b6d44c`, `crates/recomp/src/main.rs`:
24-точечный Hann-windowed sinc, отдельные интерполяторы Direct Sound FIFO A/B,
фильтрация PSG, DC blocker около 10 Гц и мягкое ограничение пиков.
Код адаптирован в `src/enhanced_audio.rs`, лицензии MIT/Apache-2.0 сохранены
в `vendor/`. Новый режим не включает высокоуровневые MP2K/GAX/R-микшеры.

Обработка работает на стороне вывода, на точной сетке 65536 Гц, без
регулировки высоты тона по заполнению очереди. В отличие от upstream,
выходной gain оставлен единичным для сравнения с нашей обычной громкостью.
Громкость SFX/Music и маршрутизация каналов берутся из исходной игры;
щелчки собственного меню и камеры проходят через прежний отдельный голос
и подчиняются SFX Volume.

Игровой микшер продолжает работать. Его исходный `audio_buf` сохраняется:
хеши видео/аудио и записи сессий проверяют прежний канонический поток.
В `info.txt` отмечается `audio_output=EnhancedOutput`. Повтор без флага
воспроизводит обычный звук, с `--enhanced-audio` — обработанный.
Диагностический `--audio-out FILE.pcm` при включённом флаге выгружает
обработанный stereo s16le 65536 Гц; без него — исходный PCM.

Тракт использует схему upstream: маршрутизация и доли FIFO
берутся в конце кадра. Очень быстрые изменения звуковых регистров внутри
кадра могут отличаться от аппаратного тракта. Оценивать качество следует
на музыке, выстрелах, двигателях и сиренах, при одинаковых SFX/Music.

## Одновременное воспроизведение эффектов

Обычный запуск EXE, `Play.bat` и `play.sh` включает режим по умолчанию.
Отключение: `--no-polyphonic-audio` (EXE/Linux) или `Play.bat -NoPolyphonicAudio`;
обработка Enhanced Output при этом сохраняется. Явные параметры
`--polyphonic-audio` / `-PolyphonicAudio` также принимаются. Режим требует
Enhanced Audio; Original Audio имеет приоритет в скриптах и лаунчере.
Настройки рендера на него не влияют. Выгрузка звука без окна по-прежнему требует
явного включения режима; игровые реплеи сохраняют записанный звуковой режим.

Драйвер USA хранит списки голосов по приоритету и воспроизводит первый голос
каждой группы. Один эффект может заглушить другой, хотя его голос остаётся активным
и продолжает продвигаться по сэмплу. Дополнительный микшер подмешивает
неприостановленные PCM-голоса после выбранных первых голосов групп эффектов 0 и 2.
Разная высота голосов группы 2 учитывается при переводе на сетку таймера выбранного голоса.
Уже слышимый первый голос исключён. Громкость, выделение и время жизни голосов
остаются под управлением игры: её пул не расширяется, удалённые звуки не оживают.

Некоторые звуки оружия игрока блокируются проверкой более высокого уровня,
пока активен конкурирующий звук транспорта, ещё до выделения PCM-голоса.
Enhanced также наблюдает за такими отклонёнными запросами игрока и воспроизводит
их PCM через дополнительный микшер. Игровая проверка и возвращаемое значение
сохраняются; громкость берётся из исходной таблицы SFX. Уже слышимые сэмплы
оригинальных каналов не дублируются. Повторный запрос перезапускает один голос
этого сэмпла; звуки NPC не добавляются с громкостью игрока. Ограниченный набор
этих голосов сохраняется в игровых реплеях. Original Audio не меняется.

Дополнительный микшер воспроизводит не более одной копии каждого PCM-сэмпла.
Уже выбранные оригинальными каналами сэмплы исключаются; повторные голоса
убираются между обеими группами эффектов. Так повторные звуки заноса или удара
не суммируются. Разные подавленные эффекты по-прежнему могут звучать одновременно,
поэтому режим намеренно отличается от обычного микса.

Дополнительные сэмплы следуют копированию префиксов звукового буфера и реальным
событиям DMA/FIFO, включая отброшенные записи, сброс и удержание уровня DAC.
Затем проходят существующие sinc-фильтр, маршрутизацию, DC-фильтр и ограничение
пиков. Игровая память, исходный PCM, выполнение CPU и контрольные суммы сессии
сохраняются. Состояние дополнительной очереди и фильтра входит в снимки игровых
реплеев и восстанавливается при возврате к игре. Диагностическая сессия отмечает
режим строкой `polyphonic_audio=1`; для выгрузки её звука явно передайте
`--enhanced-audio --polyphonic-audio`.

Для исследования драйвера нативный runtime `multi` принимает
`--sound-probe NEW_DIRECTORY` (не совмещается с трассировкой записей камеры).
В каталоге создаются `writes.csv` с записями в область драйвера и `driver.bin`:
повторяющиеся записи из u64 номера кадра в little-endian и следующих за ним
байтов EWRAM `0x02027330..0x02027f00`. Трассировка только наблюдает за игрой;
обычный запуск эти файлы не создаёт.

Дополнительно создаётся `requests.csv`: запросы выделения разовых/циклических
голосов и проверка блокировки звука оружия, с адресом вызывающего кода, актором
и возвращённым значением чтения. Запрос, отклонённый до выделения голоса, может
отсутствовать в `writes.csv`. При переносе игровых буферов IWRAM устаревшие адреса
дополнительного микшера удаляются; очередь FIFO сохраняется, размер снимков
остаётся ограниченным.
