## Запуск

Из корня проекта:

```powershell
.\experiments\recomp\play-aot.ps1
```

Запускатель собирает актуальный host с поддержкой нового ABI и передаёт
`local-output/session-recomp-0e0a5ffc/native-usa-v2.dll` плюс три исходные DLL.
Для повторного запуска без сборки есть `-SkipBuild`. Параметры `-Rom`,
`-SavePath`, `-ControlsPath` передаются обычному запускателю; профиль рассчитан
на USA. Используются прежние отдельные сохранения и настройки управления.

WASD/стрелки — движение, Space/Z — A, Shift/X — B, Q/E — L/R,
Enter — Start, Tab — Select, P — пауза, Esc — выход, F11 — полный экран.
Графические эксперименты F6/F7/F8 удалены из runtime. Выводится только
оригинальный кадр GBA. Заголовок показывает процент нативных диспетчеризаций
и накопленное число интерпретированных инструкций за сеанс.

## Что изменено

* Дополнение содержит 11 596 заранее скомпилированных входов ROM/EWRAM/IWRAM.
  Поддерживает несколько вариантов одной инструкции по одному адресу RAM.
  Варианты проверяются по содержимому; генерации кода во время игры нет.
* Добавлены нативные операции записи в PC и сдвигов регистров, включая
  границы 0/31/32/33/255 и обнуление старших битов величины сдвига.
* MRS/MSR вызывают прямые нативные операции над CPSR/SPSR с банковыми
  регистрами и ограничениями пользовательского режима.
* SWI вызывает существующие нативные BIOS HLE-функции напрямую, без
  выборки/декодирования гостевой инструкции. HALT/IRQ сохраняют прежнюю модель.
* Если старый переведённый блок доходит до неподдержанной им инструкции,
  host сначала ищет её нативную реализацию в помеченном дополнении. Лишь
  отсутствие подходящей реализации ведёт к интерпретатору и учитывается аудитом.

Модель памяти, PPU/APU, DMA, тайминги и BIOS HLE остаются в runtime. Поэтому
это этап статической рекомпиляции логики CPU. Самостоятельный игровой движок
и плавная ПК-камера ещё не готовы. Непройденные маршруты могут раскрыть новые
адреса/операции; интерпретатор пока сохранён для диагностики и таких случаев.

## Проверки и известные ограничения

* Строгие прогоны требуют нуля внешних промахов, откатов после отказа всех
  RAM-вариантов, внутренних интерпретированных инструкций и инструкций при
  пробуждении HALT. Отказ отдельного RAM-варианта сам по себе не является
  интерпретацией, если следующий вариант подошёл.
* Дополнительно 924 сравнения скомпилированных синтетических инструкций с
  интерпретатором проверили регистры, CPSR и такты. Отдельно проверены
  банковые регистры, PSR, BIOS wait/arithmetic и вложенный выбор RAM-вариантов.
  Прошли 40 тестов runtime. Оконный SDL-запуск на 120 кадров завершился
  с кодом 0 и без интерпретированных инструкций.
* **Аудио не побитово совпадает с интерпретатором.** Первый отличающийся кадр —
  467; это воспроизводится и на старых трёх DLL без дополнения. На первых
  600 кадрах отличаются 4 из 1 316 046 отсчётов PCM, максимальная разность
  256 в signed 16-bit. Новый AOT и старый runtime дают одинаковый PCM на
  этом отрезке. Субъективная слышимость и точная причина не установлены.
  Проверка `--audio-hashes` честно завершается ошибкой; это не исправлено.
* Полное скрытое состояние устройств, все миссии, все сохранения, Europe и
  самостоятельная плавная камера не проверены этим набором.

Локальные CSV, логи и PCM: `local-output/native-audit-iwram-20261022/`.
Финальные `final-walk/` и `final-explore/` прошли проверку видео и строгую
проверку нуля интерпретации в полном наборе библиотек (код выхода 0).
Результаты `verify-walk/` и `verify-explore/` содержат совпадающие хеши видео
и диагностическое расхождение аудио; их аудиопроверки не считаются успешными.

## Пересборка и воспроизведение

`local-output/session-recomp-0e0a5ffc/coverage-v2.csv` объединяет прежнее
покрытие, оба пользовательских сеанса и дополнительный RAM-вариант из регрессий. Файл содержит байты игры, в исходники не включается.
Для новой сборки выберите ещё не существующие имена C/DLL:

```powershell
cargo run --offline --release --locked --manifest-path experiments/recomp/aot/Cargo.toml -- local-output/session-recomp-0e0a5ffc/coverage-v2.csv 'Grand Theft Auto (USA).gba' local-output/native-usa-rebuilt.dll C:/msys64/mingw64/bin/gcc.exe --ram-variants
```

`native-usa.dll` требует актуальный host с `native_host::Api`, версия расширения
1. Старые бинарники probe не поддерживают эти PSR/SWI-функции. Старые три
игровые DLL продолжают использовать прежний префикс ABI.

Покадровая проверка видео и нуля интерпретации (укажите новый каталог вывода):

```powershell
python experiments/recomp/probe/verify.py --probe experiments/recomp/probe/target/release/advance-recomp-probe.exe --rom 'Grand Theft Auto (USA).gba' --input experiments/recomp/explore.input --frames 13200 --library local-output/session-recomp-0e0a5ffc/native-usa-v2.dll --library local-output/recomp-trial/labels-pass2.dll --library local-output/recomp-trial/labels-pass1.dll --library local-output/recomp-trial/baseline-before-labels.dll --output local-output/native-check-new --require-native
```

`--audio-hashes` добавляет сравнение PCM по каждому кадру; ожидаемое известное
расхождение описано выше. `--audio-out NEW.pcm` у probe пишет сырой interleaved
signed 16-bit little-endian поток. Имеющиеся файлы не перезаписываются.
