# История разработки

Эти отчёты перенесены из прежних каталогов экспериментов. Старые пути и команды
в них описывают состояние на дату отчёта и не являются актуальными командами
запуска. Рабочая структура и команды: [README](../../README.md).

`camera/` — развитие рендера и исправления камеры/спрайтов.
`aot/` — исследование таймингов CPU и расширение нативного покрытия.
