# Режимы вывода и перспективные текстуры

`play-aot.ps1` и совместимый `play-preview.ps1` по умолчанию запускают новый
renderer с перспективно корректными текстурами. Основные клавиши:

| Клавиша | Переключение |
| --- | --- |
| F6 | Enhanced / полностью Original |
| F5 | Перечитать раскладку кнопок |
| F11 | Полный экран |

Нажатие переключает один раз; автоповтор удерживаемой F-клавиши игнорируется.
F6 зарезервирована для графики. F7/F8 свободны. Выбранный режим виден в
заголовке. Настройки действуют до закрытия программы; общий `render_settings`
не зависит от SDL или памяти игры и может использоваться будущим меню.

Запуск с другим исходным выбором:

```powershell
.\experiments\recomp\play-aot.ps1 -OriginalRenderer
.\experiments\recomp\play-aot.ps1 -AffineTextures
```

На уровне probe соответствующие флаги — `--original-renderer` и
`--affine-textures`, вместе с включённым наблюдением `--camera-preview`.
Низкоуровневые диагностические команды не включают наблюдение автоматически:
старые AOT-библиотеки могут не поддерживать его требования.

## Что означает Original

Выводится исходный framebuffer GBA 240×160 с обычным
масштабированием ближайшим пикселем. Новая геометрия, сглаживание камеры,
интерполяция OBJ и исправление UV к этому изображению не применяются.
Сам renderer нового изображения не запускается. CPU, звук, ввод и сохранение
общие для режимов; переключение не требует загрузки ROM или перезапуска.

Read-only захват сцены продолжается в фоне: возврат к Enhanced получает
последнюю готовую сцену. Не поддержанные Enhanced сцены по-прежнему показывают
исходный framebuffer автоматически. Графическое переключение не выбирает
CPU-интерпретатор и не меняет счётчик нативности.

## Причина искажения текстур

Прежний renderer линейно интерполировал UV уже в экранных координатах.
Если вершины находятся на разной глубине, такая аффинная интерполяция
искажает рисунок и делает его зависимым от разбиения четырёхугольника.
Это тот же класс артефактов, который часто называют «эффектом PS1».

Теперь после отсечения в 3D интерполируются `u/z`, `v/z`, `1/z`, а итоговые
UV делятся на интерполированный `1/z`. Исходная глубина сохраняется до
растеризации. При одинаковой глубине используется прежний быстрый путь:
он математически эквивалентен и сохраняет точное округление texel.

После подтверждения качества перспективных текстур F7 освобождена.
`-AffineTextures` оставляет аффинный вариант как необязательный ретро-эффект
для будущего меню настроек. Фильтрация остаётся nearest:
эта работа исправляет перспективное растяжение, не вводит сглаживание
текстур и не устраняет всякое возможное мерцание пикселей.

## Проверки

* 49 обычных автоматических тестов; отдельно пройден изолированный SDL-тест
  с настоящей очередью F6, автоповтором, проверкой отсутствия переключения по F7,
  RGB-readback обоих режимов
  и повторным использованием двух текстур.
* Аналитический тест UV при разных глубинах и точное совпадение при одинаковых.
* Наклонная плоская поверхность даёт одинаковое изображение при двух разных
  диагоналях её разбиения на треугольники.
* Запись на 3658 кадров проверена с Perspective, Affine и Original. Видео- и
  аудиохеши игры совпадают во всех режимах. Affine полностью совпадает с
  прошлой сборкой по всем 2878 кадрам Enhanced; Perspective меняет 2432 из
  них. Original не формирует ни одного нового кадра renderer.
* Длинная запись на 12781 кадров проверена с перспективными текстурами:
  исходные видео- и аудиохеши совпадают; не теряются завершённые сцены.
* Оба запуска по PowerShell проверены с отдельными save и SDL dummy, включая
  Enhanced по умолчанию и явный Original.
