# FPS и оптимизация композиции Enhanced

Обычный `play-aot.ps1` использует обновлённый release desktop.
Заголовок показывает Native dispatch, накопленный interpreted, FPS и
текущий статус Camera preview (либо выбранного Original). Клавиши,
Renderer: Enhanced (F6) и Textures: Perspective из заголовка убраны.
Состояние паузы сохраняется; уведомления раскладки остаются в консоли.

FPS считает реально выведенные кадры за интервал примерно 0,5 с.
Учитывает выполнение CPU, Enhanced, SDL и ограничение частоты; это
не обратная величина времени одного участка рендера. Пауза и потеря
фокуса сбрасывают интервал, показывая `FPS: --`. Штатный предел GBA
остаётся около 59,7275 Гц; гостевые тайминги не менялись.

## Оптимизации

- WIN0/WIN1 раскладываются на независимые таблицы координат X и Y.
  Дробные преобразования камеры и zoom вычисляются O(width+height),
  вместо O(width*height); маска пикселя получается побитовой операцией
  и обращением к таблице. При отсутствии окон таблицы не выделяются.
- При alpha коэффициентах 0/16 или 16/0 используется точный выбор цвета,
  без расчёта каждого канала. Результат соответствует локальному PPU.
- Повторяющиеся координаты спрайта, zoom и смещение вынесены из внутреннего
  цикла: локальный X вычисляется один раз для столбца, Y — для строки.
  Порядок операций f64 сохранён; накопительных приближений координат нет.
- Повторяющиеся координаты BG2 оборачиваются битовой маской, поскольку
  аппаратные размеры текстур — степени двойки. Отрицательные координаты
  и все размеры карт проверяются сравнением с PPU.

## Проверка и замеры

Артефакты `local-output/performance-20261023/`, воспроизводимая проверка
`verify.py`, итог `verification.json`. Использованы копии initial.sav.

| Запись | Enhanced кадров | Средний рендер до/после, мс | P95 до/после, мс |
| --- | ---: | ---: | ---: |
| Поездка a184, 3658 исходных кадров | 2878 | 5,201 / 4,856 | 7,011 / 6,666 |
| Мосты 0c7f, 6156 исходных кадров | 5570 | 5,169 / 4,114 | 7,888 / 5,368 |

Среднее время рендера уменьшилось примерно на 6,6% и 20,4%.
Это время рендера, не обещание такого же прироста FPS игры.
Контрольная поездка запускалась до/после последовательно. Для мостов
эталон взят из предыдущего прогона bridge-opacity; нагрузка ОС может
различаться. Дополнительный изолированный стенд запускается попеременно
на старом/новом бинарнике (`bench-final.log`) с одинаковым входом и хешем.
В нём используются захваченные IO/OAM/VRAM, фиксированная тестовая маска
BG0 и 300 повторов композиции без исполнения гостевого CPU.

Все 9814 исходных видео- и аудиохешей совпали с пользовательскими
записями. Хеши всех 8448 Enhanced кадров полностью совпали с версией
до оптимизации; дополнительно побайтово совпали 11 выбранных изображений.
Отказов рендера нет, числа сцен и сбросов переходов не изменились.
Прозрачность мостов, анимации и интерполяция сохраняют прежний результат.

62 обычных теста проходят. Проверка подготовленных окон сравнивает их
со скалярной реализацией при wrap/пустых/перекрывающихся диапазонах,
двух окнах, масштабах 1/3 и дробной камере. Отдельный SDL-тест проверяет
реальный вывод, переключения, формат заголовка, численный FPS и паузу.
Ручной benchmark по умолчанию игнорируется вместе с SDL-тестом.

Единичные пики остаются (в новой записи мостов максимум около 43,5 мс).
Следующие оптимизации следует выбирать по конкретным моментам просадок;
среднее ускорение не означает устранение всех задержек игры.
