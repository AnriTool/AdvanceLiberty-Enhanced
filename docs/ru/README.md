# Документация AdvanceLiberty: Enhanced

[English](../en/README.md) | **Русский**

Документы описывают текущее устройство и использование. Исторические отчёты
сессий, дампы и промежуточные результаты не нужны сборке или запуску.

При изменении поведения, значений по умолчанию или форматов обновляйте
соответствующие английские и русские файлы вместе. Команды, имена параметров,
ID и примеры данных должны совпадать. Исходные тексты сторонних лицензий не меняются.
