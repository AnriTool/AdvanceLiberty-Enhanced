# Статический перевод дополнительных EWRAM-инструкций

**Актуальный результат:** 43 744 кадра четырёх маршрутов с нулём интерпретации
и совпадением всех видео/аудиохешей. Две AOT-библиотеки проверяют события
между инструкциями. [Запуск и ограничения](NATIVE-STATUS.md),
[проверка таймингов](PRECISION-20261023.md). Ниже сохранён первый этап EWRAM
для воспроизводимости исторических измерений.

Первый этап нового прохода: оригинальная логика игры с нулём интерпретируемых
ARM/Thumb-инструкций. Нативное окно само по себе этого не доказывает. Runtime
пока сохраняет модель памяти, таймингов, PPU/APU/DMA и BIOS HLE. Замена этих
подсистем игровыми ПК-системами — отдельная задача после восстановления логики.

Этот инструмент компилирует наблюдаемые EWRAM-инструкции **до запуска игры**.
Использует декодер и C-генератор локального JRickey/gba-recomp, тот же commit,
что probe. Из аудита берутся только первые 2/4 байта каждой реально достигнутой
инструкции. Непосещённый код не угадывается. На каждый вход генерируется отдельный
блок с проверкой содержимого RAM. При несовпадении сохраняется обычный откат.
Несколько вариантов инструкции по одному адресу отклоняются при сборке.
Некоторые операции генератор по-прежнему отправляет в `interp_one`.

## Повторение

Из корня проекта, PowerShell. Пути вывода должны быть новыми; каталоги создайте
заранее. Требуются исходные три DLL предыдущей попытки, Rust и MinGW GCC.

```powershell
cargo build --offline --release --locked --manifest-path experiments/recomp/probe/Cargo.toml
$probe = 'experiments/recomp/probe/target/release/advance-recomp-probe.exe'
$libs = @('local-output/recomp-trial/labels-pass2.dll', 'local-output/recomp-trial/labels-pass1.dll', 'local-output/recomp-trial/baseline-before-labels.dll')
& $probe 'Grand Theft Auto (USA).gba' experiments/recomp/walk.input 7800 local-output/before.csv multi @libs --audit local-output/fallbacks.csv
cargo run --offline --release --locked --manifest-path experiments/recomp/aot/Cargo.toml -- local-output/fallbacks.csv 'Grand Theft Auto (USA).gba' local-output/ewram.dll C:/msys64/mingw64/bin/gcc.exe
& $probe 'Grand Theft Auto (USA).gba' experiments/recomp/walk.input 7800 local-output/after.csv multi local-output/ewram.dll @libs --audit local-output/remaining.csv --require-native
```

Последняя команда пока **обязана завершаться с ошибкой**: оставшиеся откаты
не устранены. Отчёт и хеши записываются до ошибки. Проверка требует headless
single/multi; несовместимые режимы исследования с принудительной интерпретацией
отклоняются. Учтён также случай исполнения инструкции при пробуждении из HALT.
Сама обработка ожидания и IRQ через BIOS HLE не считается интерпретацией.
Нулевой результат докажет отсутствие интерпретации только на пройденном маршруте.

Для сводки адресов и поиска 32-байтовых окон в ROM:

```powershell
python experiments/recomp/probe/analyze_audit.py --audit local-output/remaining.csv --rom 'Grand Theft Auto (USA).gba' --output local-output/remaining.json
```

Совпадение окна с ROM — кандидат на источник RAM-кода, а не доказательство
его происхождения. Скрипт не читает память через шину и не меняет состояние игры.

Запуск в окне с уже построенной библиотекой:

```powershell
./experiments/recomp/play-multi.ps1 -Build -Supplement ./local-output/native-audit-20261022/ewram-final.dll
```

## Следующие препятствия

1. Несколько вариантов кода в IWRAM: статически переводить варианты отдельно и
   выбирать по содержимому, сохраняя проверки.
2. Внутренние откаты C-генератора, включая BIOS SWI и операции с PC/CPSR:
   реализовать эквивалентные нативные операции и сверить CPU/память/тайминги.
3. Добиться нуля на маршрутах старта, ходьбы, транспорта, боя, миссий и загрузки
   сохранений. Расширять покрытие по новым адресам, не выдавать один маршрут за всю игру.
4. После этого возвращаться к собственной камере и рендеру без включения
   интерпретатора. Старые F6/F7/F8 удалены из игровой сборки и перенесены в архив.

Для текущего этапа Ghidra/MCP не требуются. Они станут полезны для восстановления
функций камеры, объектов и игрового цикла после устранения технических откатов.
