# AdvanceLiberty: Enhanced

[English](README.md) | **Русский**

Неофициальная нативная оболочка для предоставленного игроком образа игры.
Проект не распространяет ROM, BIOS, сохранения или извлечённые игровые
ресурсы и не скачивает игру. Пользователь должен самостоятельно предоставить
законно полученный дамп собственного картриджа. Проект не связан с
правообладателями оригинальной игры и не предоставляет права на неё.

## Переносимая сборка

Распакуйте итоговую папку, положите свой неизменённый USA `.gba` в `roms/`
(любое имя) и запустите **AdvanceLiberty.exe**. Также работает перетаскивание
ROM на EXE. Rust, компилятор, BAT и PowerShell пользователю не нужны.
Поддерживаемый SHA-256:
`215c574d5afbda0aadbf89dc76b765cfaaeb35953eab63f7687d8bfe8a8e0f4d`.
Другие регионы и изменённые ROM отклоняются до запуска нативного профиля.

По умолчанию включены Enhanced Audio и срок жизни дропа 30 секунд.
Первый запуск использует 16:9, полноэкранный режим и прицеливание мышью
при удержании ПКМ. Уже сохранённые настройки имеют приоритет.
Для прежнего звука используйте `AdvanceLiberty.exe --original-audio`,
для исходных правил удаления — `AdvanceLiberty.exe --drop-lifetime 0`.
Настройки и сохранения создаются в `data/` рядом с EXE. Записи сессий
включены; `--no-record` отключает их. EXE не зависит от текущего каталога.

Сборка папки для распространения: `./package.ps1 -Offline`.
Результат — новая папка и ZIP в `dist/`, без ROM и пользовательских данных.
Подробности: [переносимая сборка](docs/ru/PORTABLE.md).

## Запуск из исходников

**Play.cmd** по умолчанию включает улучшенный звук Enhanced Audio и
целевое время жизни денег, оружия и трупов **30 секунд**.
Для исходного звука: `Play.cmd -OriginalAudio`.
Для исходных правил удаления: `Play.cmd -DropLifetime 0`.
Описание обработки: [Enhanced Audio](docs/ru/ENHANCED_AUDIO.md).

Двойной щелчок по **Play.cmd** или из PowerShell:

```powershell
.\play.ps1
```

Запуск работает из любого текущего каталога. Перед запуском выполняется
инкрементальная сборка; `-SkipBuild` использует готовый исполняемый файл.
Новая игра не нужна: существующий прогресс и управление перенесены.

Используется USA ROM из `roms/usa.gba`. Это локальная копия предоставленного
пользователем ROM. Европейская версия пока не поддерживается этим профилем.

Текстовые пакеты из `languages/` автоматически появляются в **Esc → Language**.
При первом запуске создаётся редактируемый `languages/en.json` с 1774
английскими записями: сюжетные тексты, служебные миссии, статистика и меню.
При расширении каталога добавляются новые ID; ваши значения сохраняются.
Выберите язык, вернитесь назад и нажмите **Save and return** — он применяется во время игры.
Дальше достаточно обычного `Play.cmd`; **Original game / ROM** отключает пакет.
Пакет v2 содержит тексты, алфавит, обычный и цветной пиксельные шрифты: новый язык не требует изменения Rust или пересборки.
Набор переведённых строк зависит от выбранного пакета; пропуски используют английский текст.
[Формат пакетов, извлечение и ограничения](docs/ru/LOCALIZATION.md).

## Управление и изображение

**Ctrl+F12** открывает панель читов справа и включает штатный чит-режим,
если он ещё выключен. **1–8** применяют чит из списка; также работают стрелки
и Enter, на геймпаде — крестовина и A. **0** переключает сам чит-режим,
**Esc / Ctrl+F12** закрывают панель. Повторное открытие уже включённый режим
не отключает. Игра продолжает работать, обычное управление во время выбора
подавляется. Комбинации отправляются исходной игре и записываются в сессию.

**9** доступна в главном меню: открывает штатную опцию **PICK LEVEL (CHEAT)**.
После ввода панель закрывается; новый пункт находится ниже **Erase Game** —
прокрутите список вниз. Тексты панели доступны в `menu` языкового JSON
через ключи `cheats_*`.
[Реализация и проверки читов](docs/ru/CHEATS.md).

Enhanced включён по умолчанию. Меню и неподдержанные сцены используют исходный
вывод. Заголовок показывает FPS, долю нативного исполнения, количество
интерпретированных инструкций и состояние Camera preview.

В 16:9 земля учитывает размеры карт всех трёх островов. Фон Enhanced-паузы
и настроек следует текущему острову: синий Portland, зелёный Staunton,
красный Shoreside. [Устройство меню](docs/ru/MENUS.md).

Экспериментальная защита денег от преждевременной очистки при нехватке
матриц спрайтов включена вместе с DropLifetime. Для отдельной проверки без
продления таймеров: `Play.cmd -DropLifetime 0 -PreserveCash`.
Подбор и лимит четырёх пачек пока сохраняются.
[Правила удержания дропа](docs/ru/DROP_LIFETIME.md).

Продлённое время жизни денег, оружия и трупов включено по умолчанию:
30 секунд. `Play.cmd -DropLifetime N` задаёт другой целевой срок (1–300),
`Play.cmd -DropLifetime 0` возвращает исходные правила.
Режим автоматически включает защиту денег.
При нехватке ресурсов старые трупы могут убираться раньше; одновременно
удерживается не более восьми выпавших оружий, денежный пул пока содержит четыре
пачки. Подбор выполняет сама игра. Параметр записывается вместе с сессией и
восстанавливается при её повторе; F6 меняет только рендеринг.
[Правила и ограничения продления](docs/ru/DROP_LIFETIME.md).

Управление Enhanced на клавиатуре включено по умолчанию и переключается
автоматически по текущему управляемому объекту игры:

| Действие | Пешком | В автомобиле |
| --- | --- | --- |
| Движение | WASD / стрелки | W/S — газ и тормоз/задний ход, A/D — руль |
| Выстрел / удар | J / левая кнопка мыши | — |
| Бег | Shift | — |
| Прыжок | Space | — |
| Войти / выйти из транспорта | F | F |
| Сменить оружие | Tab | Исходный Select на Tab |
| Ручник | — | Space |
| Сигнал / сирена | — | Shift |
| Специальная миссия | — | Caps Lock |
| Вращение башни | — | Ctrl + A/D |
| Пауза игры | Enter | Enter |

| Клавиша | Общее действие |
| --- | --- |
| F6 | Enhanced / полностью оригинальный рендер |
| F8 | Enhanced / стандартное управление GBA |
| F11 | Полный экран |
| F5 | Перечитать `controls.cfg` |
| Esc | Общее меню паузы / назад на страницах меню |
| P | Пауза исполнения |

**Esc**, действие **Pause** (по умолчанию Enter) и Start/Guide геймпада
открывают общее меню паузы. Списки паузы, Options, камеры, звука и подтверждения
выхода рисует собственный интерфейс с фоном текущего острова и жёлтым шрифтом из USA ROM.
Стрелки выбирают строку, Enter/J подтверждают, Esc возвращает назад;
строки также выбираются мышью. Геймпад: D-pad / A / B — выбор / подтверждение / назад.
Игровые действия исполняются штатной логикой и записываются как GBA-команды.
Brief, Stats, Credits, стартовый экран и слоты пока сохраняют исходные страницы.
Enter или Esc закрывает Brief/Stats/Credits. Меню сохраняет формат 3:2;
возврат в мир восстанавливает выбранные 16:9 и размеры HUD.

**Enhanced Options** доступен в паузе и внутри Options: это прежние настройки
ПК с обновлённым оформлением. Все указанные ниже пути настроек на Esc теперь
начинаются с **Esc → Enhanced Options**. В этом разделе исполнение игры и звук
полностью остановлены, изменения по-прежнему применяются только при сохранении.
**Quit to Menu → Save and Quit** сохраняет игру и возвращает к стартовому экрану;
**Quit to Desktop** предлагает **Save game and exit**, **Exit without saving**
и **Back**. Первый пункт выполняет штатное игровое сохранение, записывает файл
с резервной копией и затем закрывает приложение. При запрете сохранения или
ошибке записи приложение остаётся открытым с сообщением об ошибке.
Этот выбор доступен в загруженной игре; несохранённые изменения настроек ПК
по-прежнему отменяются при выходе и сохраняются отдельно через Save and return.
Подписи собственного меню и настроек ПК переводятся через необязательный раздел
`menu` языкового пакета; формат и пример описаны в [docs/LOCALIZATION.md](docs/ru/LOCALIZATION.md#перевод-собственного-меню).
На штатных стартовых страницах Enter подтверждает выбор, Esc возвращает назад;
привязки GBA A/B остаются альтернативами. Guide открывает Enhanced Options на этих страницах.
Во время паузы на P клавиша Esc открывает Enhanced Options напрямую.
Переходы, выбор и возврат в Enhanced Options сопровождаются оригинальным
щелчком игры. Звук есть и у добавленных строк обычного меню; громкость
следует SFX Volume, включая Off. Щелчки работают и при паузе на P.
Если меню открыто во время паузы на P, после закрытия пауза сохраняется;
отпустите кнопки меню и нажмите P для продолжения игры.

Для диагностического сравнения со старым интерфейсом:
`./play.ps1 -OriginalMenus`. Этот параметр не меняет сохранённые настройки.
Исследовательский `tools/diagnostics/record-menu.ps1` также включает оригинальное меню.

Доступны режим Enhanced/Classic, три независимых раздела привязок,
рендер Enhanced/Original, текстуры Perspective / Affine (экспериментальная
эстетика PS1) и полный экран. В разделе привязок Enter заменяет все клавиши
выбранного действия, Insert добавляет альтернативу, Delete очищает действие.
После Enter/Insert нажмите нужную клавишу или кнопку мыши. Esc отменяет захват.
Конфликты и зарезервированные кнопки отклоняются без изменения профиля;
Classic не позволяет оставить кнопку GBA без привязки.

Во время игры **V** циклически меняет камеру **Auto → Low → Medium → High**.
Клавиша настраивается в **Enhanced Options → Graphics → Cycle camera key**
(Enter — заменить, Insert — альтернатива, Delete — отключить; затем Save and return).
Переключение действует пешком и в машине, в обоих режимах управления и рендера.

В **Graphics → Aspect ratio** доступен **16:9 (experimental)**: мир расширяется
по горизонтали без растягивания спрайтов и текстур. Радар и показатели
переносятся к краям широкого кадра, сообщения сохраняют центральную привязку.
После выбора вернитесь на главный экран и нажмите **Save and return**.
При обычном оконном запуске окно принимает выбранные пропорции; F11 включает
полный экран. На экране 16:9 широкая игровая сцена занимает доступную область;
исходные меню, оригинальный рендер и откаты Camera preview сохраняют 3:2.
Для возврата выберите **Original 3:2**. Для первого запуска выбран формат 16:9.
При неподдержанной сцене возможен автоматический возврат к исходному
рендеру; причина сохраняется в журнале сессии. Режим отмечен экспериментальным.
Стиль текстур теперь находится в том же подразделе Graphics.
[Устройство широкого рендера и ограничения](docs/ru/WIDESCREEN.md).

В **HUD size** можно уменьшить HUD до 85%, 75%, 65% или 50%:
**All elements** задаёт общий размер, **Radar and markers** — радар вместе с метками,
**Status and weapon** — часы, деньги, здоровье, розыск и значок оружия,
**Messages** — надписи и сообщения фонового UI. Left/Right меняют размер,
**Reset HUD sizes** возвращает 100%. Радар сохраняет левую верхнюю привязку,
показатели — правую верхнюю, сообщения — нижнюю центральную.
Масштабирование работает в Enhanced-виде мира; оригинальный вывод и игровые
меню сохраняют исходный размер. Размеры сохраняются вместе с остальными настройками.

**Save and return** применяет изменения и сохраняет их для следующего запуска.
Esc в подразделе возвращает на главный экран настроек; Esc на главном экране
или **Discard and return** отменяет все несохранённые изменения.
Настройки графики сохраняются в `data/config/enhanced.cfg`, управление — в
`controls.cfg`; перед сохранением создаётся `controls.cfg.options-backup`.
Открытие меню само по себе файлы не изменяет. Удержанные кнопки не передаются
игре после закрытия, пока их не отпустить. Выход через меню запрашивает
подтверждение; несохранённые настройки при выходе отменяются.

Привязки редактируются в `data/config/controls.cfg`: `[GBA]` содержит исходные
десять кнопок, `[OnFoot]` и `[Vehicle]` — отдельные игровые действия.
После ручных изменений нажмите F5. `Mode = Enhanced` или `Mode = Classic` задаёт
режим при следующем запуске; F8 переключает его только до закрытия игры.
Прежняя раскладка сохранена в `data/config/controls-gba-backup.cfg`.
Профили полностью независимы: `[GBA]` применяется только в Classic и меню.
Назначение в нём R на S или Select на Shift не меняет управление Enhanced.
Pause и дополнительные кнопки также можно переназначать внутри профилей.
Удерживаемое действие при смене
контекста не превращается в другое действие без отпускания клавиши;
движение WASD при посадке и выходе продолжается.

В новых профилях прицеливание мышью уже включено. Переключатель находится
в **Esc → Enhanced Options → On-foot bindings → Mouse aim (exp.)**;
для сохранения изменений выберите **Save and return**. В Enhanced пешком удерживайте **ПКМ**:
курсор становится пиксельным прицелом, персонаж смотрит в его сторону,
J/ЛКМ стреляют туда же. Без удержания действует обычный поворот по движению.
**Aim (hold)** в том же разделе переназначает ПКМ. WASD сохраняет независимое направление движения.
Sprint по-прежнему блокирует Fire. Настройка работает также в 16:9 и с уменьшенным HUD;
в машине и Classic остаётся прежнее управление. Режим пока экспериментальный:
все виды оружия и сценарии не проверены. [Описание и проверки](docs/ru/MOUSE_AIM.md).
Геймпад сохраняет исходную раскладку GBA. [Формат настроек](docs/ru/CONTROLS.md).

Поддерживается SDL GameController. Параметры `-OriginalRenderer` и
`-AffineTextures` выбирают исходный вывод и экспериментальные аффинные
текстуры при запуске, перекрывая сохранённые параметры. `-Rom`, `-SavePath`, `-ControlsPath` задают другие пути.

По умолчанию каждый запуск создаёт новую запись в `data/sessions/`.
Закрывайте игру через **Esc → Quit game → Quit game** или крестик окна для завершённого отчёта; промежуточный аудит
обновляется во время игры. `camera-events.csv` сохраняет причины отказов Enhanced,
восстановления и изменения графических настроек; `camera-summary.txt` — итоговые
счётчики при завершении игры. Обычная игровая пауза отмечается как меню.
`-NoRecord` отключает запись;
`-SessionDirectory NEW_DIRECTORY` задаёт её каталог.

## Сборка и проверка

Нужны Rust/Cargo, MSVC Build Tools и CMake. SDL собирается автоматически
из зависимости Cargo; отдельная SDL DLL для запуска не нужна.
Первой сборке нужен доступ к зависимостям Cargo или заполненный локальный кэш.

```powershell
.\build.ps1
.\build.ps1 -Tools
.\test.ps1 -Sdl
```

`-Tools` дополнительно собирает рекомпилятор и утилиты дизассемблирования.
`-Offline` у сборки и тестов использует только локальный кэш.
Исходники `vendor/` уже включают нужные изменения, скачивать или патчить
отдельный проект перед сборкой не требуется.
В конфигурации Cargo выбрана последовательная сборка: это устраняет зависание
параллельных процессов MSBuild при сборке SDL в текущем Windows-окружении.

Для повтора завершённой записи с текущими DLL:

```powershell
.\replay.ps1 -Session session-0123456789abcdef0123456789abcdef
```

Повтор работает с копией начального сохранения в новом `artifacts/` и
сравнивает все видео- и аудиохеши с записью. По умолчанию требуется ноль
интерпретаций. `-AllowInterpreter` позволяет исследовать ещё не покрытый
маршрут; `-OutputDirectory NEW_DIRECTORY` задаёт каталог результата.

## Нативный код

Порядок и пути библиотек заданы в `native/usa/manifest.json`. Во время игры
код не компилируется. Непокрытые инструкции пока могут учитываемо перейти
в интерпретатор: ноль на проверенных маршрутах не доказывает покрытие всей игры.

Для пересборки DLL нужен **MinGW x64 GCC**, отдельно от MSVC для Rust.

После игры достаточно запустить `UpdateNative.cmd`: он дополнит накопленное
покрытие и пересоберёт/установит DLL. Длинные повторы по умолчанию не запускаются;
`UpdateNative.cmd -Verify` проверяет записи, давшие новое покрытие, перед установкой.
`CollectNative.cmd` только собирает CSV, `RebuildNative.cmd` только пересобирает
и устанавливает профиль `sessions`. [Команды, проверки и резервные копии](docs/ru/NATIVE_WORKFLOW.md).

Отдельную пересборку можно запустить так:

```powershell
.\tools\rebuild-native.ps1 -NativeProfile sessions
```

По умолчанию результат остаётся в новом `artifacts/native-build-.../`.
`-Install` устанавливает успешно собранные DLL и C в `native/usa/`;
`-NativeProfile all` пересобирает все четыре. `-Gcc PATH` задаёт компилятор.
Сначала новые откаты объединяют с соответствующим накопленным CSV в
`native/usa/coverage/`; затем пересобирают профиль и проверяют запись.
Все четыре накопленных CSV покрытия хранятся в Git вместе с манифестом.
При обновлении нативного покрытия нужно включать в коммит изменённый CSV
и `native/usa/manifest.json`. Это сохраняет найденные варианты инструкций
для пересборки на другой машине с той же USA-версией ROM.

ROM, сгенерированные из него C/DLL, сохранения и записи предназначены для
локальной работы. Лицензии исходных зависимостей находятся в `vendor/`.
