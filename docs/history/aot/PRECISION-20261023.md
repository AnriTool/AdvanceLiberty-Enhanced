# AOT с проверкой событий между инструкциями

23 октября 2026. Все четыре проверенных маршрута совпадают с интерпретатором
по каждому видео- и аудиохешу без интерпретации гостевых инструкций.
Обычный `play-aot.ps1` переключён на этот профиль.

## Подход

Старые три DLL содержали многокомандные блоки с накоплением тактов.
Найдено исполнение 5 дополнительных инструкций / 12 тактов после первой
границы кадра. Контрольный опыт с нативными одиночными инструкциями
и интерпретацией остальных совпал с интерпретатором на всех 10 814 кадрах.
См. [локализацию](TIMING-20261023.md).

Использован существующий статический генератор `--ram-variants`: отдельные
C-функции для инструкций, проверка точного содержимого RAM. После каждой
функции host проверяет кадр/HALT/IRQ. Цикл ввода получает управление на
ближайшей границе инструкции, как в интерпретаторе. AOT-функция содержит
заранее переведённую операцию, без выборки и декодирования гостевого opcode
для её исполнения. Создание C/DLL происходит до запуска. BIOS HLE прежний.

* `native-precise.dll`: 87 685 входов/вариантов. Прежнее покрытие объединено
  с аудитом инструкций контрольного повтора 844a4306.
* `native-extra.dll`: 7940 входов/вариантов из аудитов walk, explore и 0e0a5ffc.

Неподдержанных инструкций в обоих случаях — 0. Разделение позволяет не
пересобирать основную DLL для новых адресов. Host допускает одну или несколько
DLL в multi/play. `play-multi.ps1 -Standalone -Supplement PATH1,PATH2`
не добавляет старые DLL; этот способ теперь использует `play-aot.ps1`.

## Проверка

| Повтор | Кадры | Интерпретация | Отличия видео/аудио | Время headless, с |
|---|---:|---:|---:|---:|
| 844a4306 | 10 814 | 0 | 0 / 0 | 42,405 |
| 0e0a5ffc | 11 930 | 0 | 0 / 0 | 59,827 |
| walk | 7800 | 0 | 0 / 0 | 18,264 |
| explore | 13 200 | 0 | 0 / 0 | 30,962 |

Всего 43 744 кадра. Финальные аудиты содержат только заголовок;
`--require-native` прошёл во всех случаях. Сравнивались все строки CSV,
включая длину, номер кадра, framebuffer и аудиосэмплы. Для пользовательских
сеансов использованы отдельные копии initial.sav. Реальный прогресс и исходные
записи не изменены. Времена получены при параллельных headless-проверках,
это не измерение кадровой частоты видимого SDL-окна.

Первый отдельный прогон 844a4306 одной основной DLL уже совпал с интерпретатором
без интерпретации, занял 37,656 с. Другие пути сначала совпали с откатами,
затем после сборки native-extra повторены полностью нативно.
Устранено и прежнее небольшое различие звука walk/explore.

19 тестов host прошли. SDL smoke с dummy video/audio и software renderer:
120 кадров за 2,010 с, `Native dispatch: 100.00% | interpreted: 0`.
Запись сеанса содержит обе актуальные DLL, хеши, ввод и пустой fallback-аудит.
Это не ручная проверка графики или реального аудиоустройства.

## Артефакты и воспроизведение

`local-output/native-timing-20261023/` содержит C, DLL, исходные аудиты,
coverage CSV, логи и `result.json`. Итоги: `final-{first,latest,walk,explore}.csv`,
одноимённые `.log` и `-audit.csv`. Первый эталон:
`session-recomp-844a4306/oracle.csv`; второй — `latest-oracle.csv`.
Walk/explore: `native-audit-iwram-20261022/verify-{walk,explore}/interp.csv`.

SHA-256:

```text
native-precise.dll 8dd9244a6b28a6d150288a2cec374cf261ab6d474bf5a39268560242144421a9
native-extra.dll   806d594dbb1ef779dd1a3930a86bc3b1febe3b43eaea4a03932e338826ee47c1
```

Повторная генерация в новые имена:

```powershell
cargo run --offline --release --locked --manifest-path experiments/recomp/aot/Cargo.toml -- local-output/native-timing-20261023/coverage.csv 'Grand Theft Auto (USA).gba' local-output/native-timing-20261023/rebuilt-core.dll C:/msys64/mingw64/bin/gcc.exe --ram-variants
cargo run --offline --release --locked --manifest-path experiments/recomp/aot/Cargo.toml -- local-output/native-timing-20261023/extra-coverage.csv 'Grand Theft Auto (USA).gba' local-output/native-timing-20261023/rebuilt-extra.dll C:/msys64/mingw64/bin/gcc.exe --ram-variants
```

Библиотеки производны от ROM пользователя и остаются локальными.
Неизвестные маршруты могут раскрыть новые адреса. Независимый GBA-эталон
ещё не проверялся. Полностью нативный повтор устранил наблюдаемое расхождение;
эксперимент не устанавливает единственную причину каждого отличия старых блоков.
