AdvanceLiberty: Enhanced — Linux x86_64

ROM, BIOS и извлечённые ресурсы оригинальной игры не поставляются и не
скачиваются. Нужен ваш легальный неизменённый дамп картриджа версии USA.

1. Распакуйте архив целиком, сохранив структуру каталогов.
2. Положите USA .gba в roms/ под любым именем.
3. Запустите ./AdvanceLiberty из этой папки или через файловый менеджер.
   Если право запуска потерялось: chmod +x AdvanceLiberty

Нужен Linux x86_64 с рабочим столом X11 или Wayland, glibc и обычными
системными библиотеками звука и графики. SDL2 встроена в приложение.
Для готового пакета Rust, Python, компилятор, слой совместимости Windows
и shell-скрипты не нужны. Пакет следует собирать на самой старой версии
glibc, которую планируется поддерживать: это не универсальный бинарник.

Esc > Enhanced Options открывает настройки. Сохранения, настройки и записи
лежат в data/ рядом с программой; папка должна быть доступна для записи.
Значения Enhanced по умолчанию сохраняются и в этой сборке.
