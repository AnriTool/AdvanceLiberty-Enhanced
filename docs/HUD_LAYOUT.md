# Масштабирование игрового HUD

Настройка: Esc → HUD size. Доступны 100, 85, 75, 65 и 50 процентов.
All elements меняет все три группы; остальные пункты независимы.
Save and return сохраняет HudRadar, HudStatus, HudMessages в enhanced.cfg.
Отсутствие новых полей в старом файле означает 100%, ручная миграция не нужна.

## Состав и координаты

Источник — исходные координаты GBA 240×160. Прямоугольники полуоткрытые.

| Группа | Область источника | Точка привязки | Состав |
| --- | --- | --- | --- |
| Radar | x=[0,64), y=[0,64) | (8,8) | BG1-карта, рамка и OBJ-метки |
| Status | x=[120,240), y=[0,64) | (232,8) | Часы, деньги, здоровье, розыск, OBJ оружия |
| Messages | Остальной BG1 | (120,152) | Название района и сообщения вне первых двух областей |

Группировка проверена на семи сохранённых игровых кадрах: пешком,
в автомобиле, во время удара и после возвращения из паузы.
Это границы групп, а не отдельных цифр/иконок. Независимые размеры здоровья
и оружия внутри Status пока не добавлялись.

В широком формате радар и его OBJ-метки получают общую левую привязку,
показатели и оружие — правую. Сообщения центрируются относительно широкого кадра.

## Реализация

hud_layout.rs задаёт размеры, привязки и обратные таблицы координат.
object_projection.rs использует их при композиции BG1 и экранных OBJ.
Сначала строится мир: уменьшение HUD раскрывает мир под ним, не переносит
пиксели уже готового кадра и не уменьшает попавшие в его область автомобили.
Масштабируются только экранные OBJ приоритета 0 внутри Radar/Status.
Для мировых объектов сохраняются прежние координаты, масштаб и интерполяция.

Признак обычного USA HUD — экранный OBJ оружия 32×32 в (200,8).
Без него преобразование отключено: BG1 может содержать диалог или панель.
Оригинальный рендер и неподдержанные Enhanced-сцены используют исходный HUD.
При 100% используется прежнее чтение BG1 без дополнительных таблиц.
Гостевая память и исходные буферы не изменяются.

## Проверка

Артефакты: artifacts/hud-20261024/.

- 86 тестов runtime и один тест AOT; две отдельные SDL-проверки.
- SDL: изменение общего размера и размера радара, сохранение/перезапуск,
  ошибка сохранения без применения незаписанных изменений.
- Семь захваченных сцен × 100/75/50%; центр мира остаётся идентичным.
- Контрольный повтор 3500 кадров с camera-preview: исходные видео/аудиохеши
  совпадают с предыдущим эталоном, интерпретированных инструкций — 0.
- В этом повторе также зарегистрирован один Scene refresh timeout;
  весь маршрут не является проверкой отсутствия откатов камеры.

Ручной тест захваченных сцен запускается отдельно, в новый выходной каталог:
ADVANCE_HUD_SCENES указывает на каталог дампов 001675..003450,
ADVANCE_HUD_OUTPUT — на новый каталог изображений;
cargo test --release --package gta-advance hud_captured_composition -- --ignored --nocapture.
