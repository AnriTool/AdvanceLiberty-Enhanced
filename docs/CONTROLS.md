# Настраиваемое управление Enhanced

Enhanced на клавиатуре/мыши включён в `data/config/controls.cfg`.
F8 временно переключает Enhanced/Classic, независимо от рендера F6.
Для постоянного выбора измените `Mode = Enhanced` на `Mode = Classic`.
F5 перечитывает файл, при ошибке сохраняется предыдущая рабочая настройка.

## Привязки

В `[GBA]` определены все десять исходных кнопок: A, B, Select, Start,
Right, Left, Up, Down, R, L. Эта секция используется в Classic и меню.
Прежние пользовательские назначения J/Space/F/H сохранены. Файл до
включения Enhanced — `data/config/controls-gba-backup.cfg`.

В `[OnFoot]` доступны Up, Down, Left, Right, Fire, Sprint, Jump,
EnterVehicle, ChangeWeapon, Pause и AuxiliaryR. В `[Vehicle]` — Accelerate, BrakeReverse,
SteerLeft, SteerRight, ParkingBrake, Horn, SpecialMission, TurretModifier
ExitVehicle, Pause и ChangeWeapon. Профили полностью независимы: назначения
`[GBA]` действуют только в Classic и меню, а в Enhanced используются только
действия соответствующего профиля. Pause по умолчанию — Return,
AuxiliaryR пешком — H, ChangeWeapon в машине — Tab (исходный Select).
Эти дополнительные поля можно не указывать, тогда действуют их значения
по умолчанию. Клавишу GBA R можно назначить на S, а Select на Shift без
конфликта с движением и сигналом в Enhanced.

Значения — физические SDL-названия клавиш; альтернативы разделяются запятой.
Регистр раскладки Windows не меняет расположение кнопки. Поддерживаются
`MouseLeft`/`LMB`, `MouseMiddle`/`MMB`, `MouseRight`/`RMB`.
`None` отключает отдельное действие Enhanced. Пример изменения:

```ini
[OnFoot]
Fire = J, MouseLeft
Sprint = Left Shift, Right Shift
Jump = C
EnterVehicle = F
ChangeWeapon = Tab
Pause = Return
AuxiliaryR = H

[Vehicle]
Accelerate = W, Up
BrakeReverse = S, Down
SteerLeft = A, Left
SteerRight = D, Right
ParkingBrake = Space
Horn = Left Shift, Right Shift
SpecialMission = CapsLock
TurretModifier = Left Ctrl, Right Ctrl
ExitVehicle = F
Pause = Return
ChangeWeapon = Tab
```

Это фрагмент существующего файла: секцию `[GBA]` необходимо сохранить.
Неуказанные Enhanced-действия получают значения по умолчанию. Одна клавиша
может иметь разные действия пешком, в машине и в Classic; конфликт двух
одновременных действий внутри одного контекста отклоняется. Модификатор
башни использует текущие SteerLeft/SteerRight, поэтому переназначение руля
также меняет сочетание вращения башни. Caps Lock действует при физическом
нажатии, а не как постоянно включённое состояние.

P, Escape, F5, F6, F8 и F11 зарезервированы для окна. Мышь не меняет
направление прицеливания: левая кнопка воспроизводит исходный Fire.
SDL GameController сохраняет исходную GBA-раскладку; Enhanced-профили
сейчас относятся к клавиатуре и мыши.

В Enhanced пешком зажатый Sprint блокирует Fire, включая кнопку мыши:
бег с ударом не превращается в прыжок. Отдельный Jump продолжает работать
во время бега. Правило относится к действиям и сохраняется при переназначении
их клавиш; Classic использует исходные сочетания игры.

## Как определяется контекст

`control_context.rs` читает указатель USA `02000f10`. Исходный код ROM
`08001484..080014a0` также читает этот указатель и байт типа объекта +8:
2 — персонаж, 4 — транспорт. При посадке глобальный указатель начинает
указывать на автомобиль, при выходе возвращается на персонажа.

Дополнительно проверяются диапазоны/выравнивание EWRAM, тип ROM-дескриптора,
согласованность физического положения и обратной ссылки анимации.
Меню с отключёнными мировыми BG2/OBJ сохраняет обычные GBA-кнопки.
Forced blank отдельной фазы загрузки не меняет раскладку управления.
Определение не зависит от положения камеры, интерполяции и выбора рендера.
Гостевая память не изменяется.

Все действия преобразуются в исходные активные-низкие кнопки GBA:

| Действие | Передаётся игре |
| --- | --- |
| Fire / Sprint | A / B |
| Jump | A+B |
| EnterVehicle / ExitVehicle | L |
| ChangeWeapon | Select |
| Accelerate / BrakeReverse | A / B |
| SteerLeft / SteerRight | Left / Right |
| ParkingBrake | R |
| Horn | Up+R |
| SpecialMission | L+R |
| TurretModifier + направление | A+B+Left/Right |

`InputLatch` предотвращает превращение удержанного Shift из бега в сигнал,
Space из прыжка в ручник и F из посадки в выход. Действие необходимо
отпустить и нажать заново. Одинаковое направление движения сохраняется
при смене пешего и автомобильного контекста; при открытии меню нажатие
не переносится на навигацию. В Classic новые ограничения не применяются.

## Проверка

Артефакты: `artifacts/controls-20261024/`. На пробном маршруте зафиксированы
пеший режим с кадра 766, управление машиной с 1765, выход с 2503,
меню паузы с 3122 и возврат к персонажу с 3333.

Сравнены исходная последовательность GBA-кнопок и последовательность,
полученная из WASD/F/Space через тот же Controls/InputLatch, что использует
окно. Сравнение охватывает посадку, езду, выход, прыжок и меню: все 3500
исходных видео- и аудиохешей совпали, интерпретированных инструкций — 0.
Заменённый на MouseLeft выстрел даёт тот же поток кнопок, что J.
Сохранение пользователя проверено по SHA-256 и не изменялось.

Для повторяемого преобразования физического тестового маршрута добавлен
пример `examples/verify-controls.rs` (запуск `cargo run --example verify-controls -- ...`).
Диагностика `--control-state NEW_FILE.csv` пишет контекст, указатель объекта,
состояние дисплея и вспомогательный флаг по кадрам. Она доступна и при
повторе без окна, не меняет CPU/память и не подменяет записанные GBA-кнопки.

При исправлении независимости профилей прошли 78 тестов runtime;
SDL-проверка переключения режимов и перечитывания настроек выполнена отдельно.
Автотесты проверяют профили, мышь, переназначение, конфликты, сохранение
старого формата, защиту удержанных кнопок, невалидные указатели и меню.
SDL-тест дополнительно проверяет F8 без влияния на рендер и перечитывание
изменённой клавиши прыжка через F5. Башня танка и выполнение конкретных
специальных миссий пока проверены на уровне передаваемых сочетаний GBA;
проверки этих действий в соответствующем транспорте ещё не было.
